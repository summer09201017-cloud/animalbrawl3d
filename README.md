# 🐾 毛毛大亂鬥(animalbrawl3d)

3D **物理布娃娃**派對遊戲。四隻可愛動物,把對手推下浮空平台就得分。
同一台電腦兩個人一起玩,或一個人對電腦。

> Party Animals 那型 —— 樂趣不在打得準,在**站不穩**。

## 怎麼開始玩

**線上直接玩**(不用裝任何東西):<https://hfpc-animalbrawl3d.pages.dev>
也在總入口大廳的「**經典街機合輯**」裡(遊戲左上角有「← 返回大廳」)。

想在本機改:雙擊 `run.bat`(第一次會自己 `npm install`),或手動 `npm install` → `npm run dev`。

> 📱 **手機/平板請橫著拿** —— 直向會蓋一張「請把手機轉成橫向」的提示,
> 因為橫的才看得到整個台子與兩隻動物。

### 操作

| | 移動 | 跳 | 出拳 | 抓/丟 |
|---|---|---|---|---|
| **一號**(藍) | `W A S D` | `F` | `G` | `H` |
| **二號**(橘) | 方向鍵 | 小鍵盤 `1` | `2` | `3` |

- `V` 切換視角,四個輪流:**固定機位(預設,不轉)→ 側面轉播 → 高空俯瞰 → 跟隨(會轉)**
  · `R` 重新開一場 · 左上角「← 返回大廳」隨時可以離開(比賽中會先問一次)
- **手機/平板**:左下角搖桿 + 右下角四顆鈕(只操作一號,適合一個孩子對電腦)
- 移動方向永遠是**畫面上的方向** —— 按右就往畫面右邊走,不管現在是哪個視角

### 開場可以選

- 兩邊各自要哪一隻動物(**小貓 / 小狗 / 小兔 / 小鴨**)
- 哪一邊給電腦操作(預設二號是電腦)
- 幾分獲勝(1 / 2 / 3 / 5)
- 台子大小:**小**(很快掉)/ 中 / **大**(慢慢玩)
  → 給小小孩玩建議選「大」,他們比較不會一直掉下去

## 玩法

- 把對手**推下台**就得 1 分,先到設定分數的贏
- 出拳打中會讓對手**頭暈**一下(那時候他站不穩,最好推)
- **抓住**對手可以拖著他走,再按一次就用力**丟出去**
- 自己掉下去不會扣分,但對手得分;**兩隻同時掉下去,誰都不得分**
- 快掉下台時 HUD 會出現「⚠ 快掉了!」

## 一檔一責

| 檔 | 責任 |
|---|---|
| `src/physics.js` | 純 Rapier:布娃娃、主動平衡、走跳、揮拳、抓丟、掉台判定。**刻意不 import three** |
| `src/game.js` | three 場景 + 每幀從物理同步 + 回合規則 + AI + **四**檔視角 |
| `src/main.js` | 選單 / HUD / 鍵盤 / 觸控 / 返回大廳 / 版本號。不碰物理內部,只透過 `Game` 的方法 |
| `src/audio.js` | 合成音效(零音檔、離線可用) |
| `public/` | PWA 殼層:`sw.js` / `icon.svg` / `manifest.webmanifest`。**必須放這裡**,vite 只複製 `public/` |
| `test/` | `npm test` —— **119 項**,其中物理那 50 項跑的是真的 Rapier |
| `scripts/browser-verify.mjs` | 真瀏覽器驗收:`npm run verify:quick`(30 項 21 秒)/ `npm run verify`(52 項 155 秒) |

## 改內容要動哪裡

| 想改 | 改哪裡 |
|---|---|
| 動物的顏色 / 耳朵 / 尾巴 | `src/game.js` 開頭的 `KINDS` |
| 台子大小的三個選項 | `index.html` 選單的 `#ar`(值就是半徑,公尺) |
| 走多快、跳多高、拳多重 | `src/physics.js` 的 `TUNE`(⚠ 全部按「一隻 8.9 公斤的幼獸」算過,改質量要重算力道) |
| 鏡頭距離 / 俯角 | `src/game.js` 的 `_updateCamera`(⚠ 改完要跑**全套** `npm run verify`,那裡有構圖斷言) |
| 版本號與「這版多了什麼」 | `src/main.js` 的 `VER` / `VER_NOTES`,**同時** bump `public/sw.js` 的 `CACHE` |

## 給接手的人:一句話版

物理與規則都能在 **node headless** 下驗到真值(Rapier 的 compat 版在 node 跑得起來),
所以**改完一定要跑 `npm test`** —— 它抓得到「站不起來 / 推不下台 / 打不到人」這種只有玩過才會發現的壞法。

⚠ 但 headless **驗不到「看不看得見」**:0901 就有兩個 bug(HUD 整組隱形、比賽結束後
「再來一場」鈕不出現)在 119 項全綠的情況下躲過去,是真瀏覽器截圖才抓到的。
⇒ 改到畫面就跑 `npm run verify:quick`;改到鏡頭或輸入就跑 `npm run verify`。
